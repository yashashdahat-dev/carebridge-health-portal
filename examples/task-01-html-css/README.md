# Task 01 — Semantic HTML5 & Accessible CSS3

This directory holds the original foundational implementation of the **CareBridge Clinical Portal**:

## Key Features
- **Semantic HTML5 Landmarks**: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>` with explicit ARIA roles.
- **Accessible Form Controls**: Controlled clinical intake fields with `<label for="...">`, required indicators, fieldsets, and radio/checkbox groups.
- **Pure CSS3 Design System**:
  - CSS Custom Properties (Theme tokens for Light, Dark, and High-Contrast modes).
  - Dynamic typography scaling with `calc()` and CSS variables.
  - Responsive layouts via CSS Grid (`grid-template-columns: 1fr 1fr`) and Flexbox.
  - WCAG 2.1 Level AAA compliant focus rings (`outline: 3px solid #f59e0b`).
- **Files**:
  - `index.html`: Complete standalone 1,475-line accessible clinical portal markup.
  - `styles.css`: Full clinical CSS3 design tokens and stylesheets.
